# maket-photon

Статична реалізація макета музичного сайту / музичного плеєра з PSD-макета.

## Структура

- `index.html` — головна сторінка
- `styles.css` — стилі
- `player.js` — логіка плеєра
- `assets/` — зображення та інші ресурси
- `yarkij-maket-muzykalnogo-sajta-music-player.psd` — вихідний макет (джерело правди, лише для читання)

## Запуск

Сторінка статична — відкрийте `index.html` у браузері або відслужіть папку будь-яким статичним сервером, наприклад:

```bash
npx serve .
```

## Розробка

Зміни беруться з PSD-макета (шляхи, кольори, шрифти, тексти). Перевірка — скріншот у браузері та порівняння з макетом.
